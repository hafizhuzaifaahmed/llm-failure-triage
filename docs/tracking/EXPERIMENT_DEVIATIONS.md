# Deviations from the approved Phase 2 methodology

Every entry states the Phase 2 text, what changed, why, and the effect on RQs/hypotheses.
No deviation changes a research question, hypothesis, metric, confirmatory endpoint, decision rule or model role.

| ID | Phase 2 design | Change | Reason | Effect on RQs / H | Status |
|---|---|---|---|---|---|
| X-01 | M1 = version-pinned DeepSeek-V3-family model (provider implied: DeepSeek). | Same model family and a pinned snapshot (`deepseek/deepseek-chat-v3-0324`), served via OpenRouter, pinned to the GMICloud fp8 endpoint with fallbacks disabled. | DeepSeek's API retired V3 (checked 2026-10-30). | None if approved; provider and returned model id are logged per call. | **awaiting approval** |

| X-04 | C1: "All builds and executions run in one Docker image." | WSL2 Ubuntu 22.04.5, Defects4J 3.0.1 (`v3.0.1`, `6d54320e`), OpenJDK 11.0.32, recorded in `env/environment_manifest.json`; reference Dockerfile provided, not used. | Docker not installed on the host. | Reproducibility via the manifest, not an image digest. | adopted |

| X-06 | GLMM effects "reported as odds ratios with CIs". | Odds ratios from the statsmodels fit with **bug-level cluster-bootstrap** intervals; the VB intervals are not reported. | Simulation with known effects (20 data sets, `tests/unit/glmm_coverage_record.json`): VB 95% intervals covered the truth in only 50–70% of cases; bug-level variance collapsed (0.05 vs 0.4). The bootstrap intervals' own coverage has not been simulated (cost). | adopted |
| X-07 | C9: "sample TF … stratified by project, to a PF:TF ratio of 1:2" (within/overall not specified). | **Proposed, not applied:** apply the ratio overall with proportional TF allocation. | X-08 | D2: "up to 2 mutants per D1-test focal method … killed by at least one developer test". | Killed = FAIL or EXC in Major's kill matrix (TIME not counted), and additionally verified at source level: the materialised mutant must compile and fail ≥ 1 relevant developer test. Focal methods whose class has no applicable mutant, or with no killed mutant, contribute no D2 instance. | Prevents a timeout or an unplaceable edit from standing in for an observable fault. | Stricter than Phase 2 wording; D2 size is whatever survives (reported). | adopted |
| X-09 | Development pilot on "the development split". | The judged pilot set is capped at 150 instances (proportional, seeded subsample preserving 1:2). | Bounds pilot spend for the approval request. | Pilot only; D1-test is never capped. | proposed with the pilot approval |

**X-07 update (2026-11-01, D-53):** applied for D1-test — overall 1:2 with proportional, project-stratified TF allocation. Dev pilot unchanged (within-project). Within-project kept as a scored sensitivity alternative.
